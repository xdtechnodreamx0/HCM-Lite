# Build status

Updated: 2026-11-14 (Asia/Karachi)

## Current state

The Next.js app, role-scoped portal, MongoDB-backed service layer, Route Handlers, responsive CSS, four appearance modes, live people search, isolated demo workspace, account creation and recovery, optional SMTP or Resend email delivery, optional Gemini assistant, HR self-service, and server-verified geofenced check-in are present in this checkout.

Release commits `210eefe` (portal release), `657422d` and `9145955` (AI reliability), `bcd7675` (cold-start budget), `1a10a8c` (SMTP delivery), `744590a` (sign-in entry cards), `755cc75` (rich demo workspace and attendance/payroll math), and `6b1c7ca` (static `pdf-lib` import so payroll and payslips load on Vercel) add self-serve company workspaces, 6-digit email verification, profile-only employees, a separate read-only customer demo, and a one-click demo launcher. Company sign-up is available only after the first workspace is initialized and only when email delivery is configured; it rolls back every record if verification email delivery fails. The first workspace still uses one-time setup. The customer portal is read-only, reads a sanitized company snapshot, and grants no staff API access; outside demo mode it serves a fixed fictional sample so production still has a working customer experience. `DEMO_MODE=true` gates one-click demo login against the seeded database; production keeps it false.

The demo seed now produces 17 employees and five usable personas: Nadia Rahman (Admin), Iqra Javed (HR), Sana Malik, Taimur Raza, and Sarmad Baig (Employees). All five accept `12345` and are available from `/demo`. A reseed purges the marked demo company first, so the snapshot is exact and repeatable. The snapshot includes 6 departments, 8 designations, 10 holidays, 3,623 attendance rows, 9 leave requests, 9 announcements, 20 notifications, 3 attendance corrections, 11 payroll runs (January–October finalized, November draft), and 22 audit events. Approved leave overrides attendance punches, leave days are deduplicated, attendance rate is capped at 100%, and mid-month payroll drafts count absences only through today.

AI uses the `gemini-flash-lite-latest` alias as its configured primary. Each model call has a 12-second SDK deadline and an 11-second attempt budget; the next candidate starts after a 2-second stagger, capped at a 4-second start, so the first healthy model wins instead of waiting out each slow one. The optional fallbacks are `gemini-3-flash-preview`, `gemini-3.5-flash-lite`, and `gemini-3.5-flash`, and the overall request budget is 42 seconds. Policy questions are answered in one model call because the workspace attendance policy is injected server-side; only data questions use the two-stage tool-selection flow. Headcount and leave answers come from authorized server tools; no model output is faked. The AI audit log records the model that answered.
